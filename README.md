Entry for make.fun's "Out of Tokens, Mid-Sentence" bounty: the funniest
one-line error message an AI agent shows when it runs out of tokens
mid-sentence.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

The program writes exactly one line (1-140 characters) to
`entry.txt` in the output directory.
